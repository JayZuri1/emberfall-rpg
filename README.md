# Emberfall apps
Add everything in this folder to the ROOT of your repo (keep the folder names, including .github).
- Install as app (instant): open the site in Chrome > menu > Install app / Add to Home screen.
- Android APK + Windows EXE: GitHub > Actions > "Build apps" > Run workflow > download the artifacts when it finishes.
Both apps open https://jayzuri1.github.io/emberfall-rpg/ so game updates reach everyone without rebuilding.
