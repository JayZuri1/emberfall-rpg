# Emberfall online setup (free)
1. supabase.com > New project (free). 
2. SQL Editor > paste supabase.sql > Run.
3. Authentication > Providers > Email: turn OFF "Confirm email".
4. Project Settings > API: copy Project URL + anon public key into the top of online.js.
5. Push all files to GitHub, Settings > Pages > deploy from main. Share the URL.
